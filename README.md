# 🎯 Foco nos Estudos

> Uma extensão para navegadores focada em minimizar distrações e impulsionar a produtividade durante sessões de estudo.

---

## 📌 Sobre o Projeto

O **Foco nos Estudos** é uma extensão desenvolvida para ajudar estudantes e profissionais a manterem a concentração naqueles momentos cruciais. Utilizando a API `declarativeNetRequest` (Manifest V3), a extensão bloqueia sites de redes sociais e plataformas de entretenimento, exibindo uma tela overlay customizada para reforçar o foco nos seus objetivos.

---

## 🚀 Funcionalidades

- 🚫 **Bloqueio de Sites Distraidores:** Interceptação dinâmica de redes sociais e páginas de entretenimento.
- 🎨 **Interface Intuitiva:** Popup de controle prático para ativar/desativar o bloqueio rapidamente.
- 🖥️ **Overlay Personalizado:** Subtitui o acesso bloqueado por uma tela motivacional focada no estudo.
- ⚡ **Desempenho Leve:** Construído sobre o padrão **Manifest V3** para máxima performance e baixo consumo de memória.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagens:** HTML5, CSS3, JavaScript (ES6+)
- **Extensão:** Web Extensions API (Manifest V3)
- **Controle de Regras:** `declarativeNetRequest`

## 📦 Como Instalar no Navegador (Modo Desenvolvedor)

1. **Clone o repositório:**
   ```bash
   git clone [https://github.com/damiannydara4-cmyk/Foco-Nos-Estudos.git](https://github.com/damiannydara4-cmyk/Foco-Nos-Estudos.git)
2.Acesse o gerenciador de extensões do seu navegador:

No Google Chrome: acesse chrome://extensions/

No Brave: acesse brave://extensions/

No Edge: acesse edge://extensions/

3.Ative o "Modo do desenvolvedor" no canto superior direito da página.

4.Carregue o projeto:

Clique no botão "Carregar sem compactação" (Load unpacked).

Selecione a pasta onde você clonou o repositório.

Pronto! A extensão aparecerá na sua barra de ferramentas.
